# APEXU QCTO Monitoring System

A browser-based dashboard for tracking QCTO accreditation compliance: learner records, enrolments, EISA assessments, monitoring visits, attendance, PoE checklists, clients, and assessor accreditation.

Live site: https://apex1-consol.github.io/

Built on Supabase with a localStorage cache for offline use. User data snapshots are synced to a private companion repo.
