# What's New in the Report Generator — PM Quick Start

Two additions just went live on the Executive Summary page of every client report. Nothing about how you generate, edit, or send reports has changed — these just make the summary page do more of the thinking for you.

## 1. Recommended Next Steps

Right below the Headline on the Executive Summary page, you'll now see a box that turns the attendance, risk, and EISA numbers into a plain-language action list — things like "Schedule a one-on-one intervention for the 2 learners flagged high risk" or "3 learners still to be booked for EISA."

It's generated automatically from the same data already on the page, so it will never say something the rest of the report doesn't back up. If a programme has no outstanding issues, you'll see a green "no action required" message instead of an empty box.

**What to do with it:** read it before sending. It's a starting point, not a final word — if you know more context than the raw numbers show (e.g. a learner's already been contacted), it's fine for your written narrative elsewhere in the report to reflect that.

## 2. Month-over-month trend

Next to Attendance %, Flags Raised, and EISA Completed % on the Executive Summary donuts, you may see a small pill like **up 4% vs last month** or **down 2 vs last month**. Green means things improved, red means they moved the wrong way — the colour logic accounts for the fact that a rising attendance number is good, but a rising flag count is bad.

**Important — you won't see this yet on most reports.** The trend needs a saved report from the previous month to compare against. Since this just launched, the *first* report you generate for each programme won't show a trend chip — that's expected, not a bug. It'll start appearing from the second report onward, once there's a "last month" saved to compare.

## Nothing else changes

Your workflow is exactly the same: generate, review, edit narratives, check the readiness checklist, Send for Review. These two additions live only on the Executive Summary page and don't affect data entry, EISA capture, attendance, or sign-off anywhere else.

## If something looks off

If a Recommended Next Steps item doesn't match reality, or a trend number looks wrong, flag it before sending the report to the client — treat it the same as any other draft content that needs a human check before it goes out.
